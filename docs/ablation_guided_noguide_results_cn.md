# 4.3 A* 引导消融实验结果

## 4.3.1 实验目的与协议

为验证 A* 参考路径信息在多智能体局部协调中的作用，本文设置 MAPPO-Guided 与 MAPPO-NoGuide 两组实验。两组实验使用相同的机场港湾区拓扑、航班计划、连续飞机动力学、动作空间、奖励函数、训练回合数、随机种子和评估协议，唯一差异是是否将 A* 参考路径特征输入航空器的局部观测。

在 MAPPO-Guided 中，A* 根据当前节点和目标节点生成参考路径，并将参考路径下一节点、剩余路径代价和目标方向等信息编码到观测中。该路径不直接规定航空器必须执行的动作，最终动作仍由策略网络输出。在 MAPPO-NoGuide 中，关闭上述参考路径观测特征，但保留相同的物理约束、动作掩码和执行环境。两组模型均在固定评估集上进行确定性评估，结果不使用训练阶段单个 episode 的即时奖励或完成数量作为结论依据。

## 4.3.2 训练过程比较

图 4.1(a) 展示两组模型的训练回报滑动平均，图 4.1(b) 展示固定评估集上的安全服务完成率。MAPPO-Guided 在训练后期能够形成较稳定的可执行策略，其最佳选择模型在固定评估集上取得 79.38% 的安全服务完成率和 30.00% 的完整任务成功率。MAPPO-NoGuide 的评估曲线长期处于较低水平，最佳选择点出现在约第 2,000 个训练回合，但安全服务完成率仅为 34.38%，完整任务成功率为 0%，并且后续评估仍伴随较高的超时比例和冲突数量。

该结果表明，在当前港湾区拓扑和资源占用规则下，仅依靠邻近航空器状态、目标状态和局部可行动作掩码，策略难以稳定建立从当前位置到目标区域的方向性决策。A* 特征提供了一个不强制动作执行的全局路径先验，使策略能够在局部冲突协调过程中保持目标导向，从而减少无效探索、反复等待和错误分支选择。

## 4.3.3 固定评估集结果

| 指标 | MAPPO-Guided | MAPPO-NoGuide |
|---|---:|---:|
| 安全服务完成率 | 79.38% | 34.88% |
| 完整任务成功率 | 34.00% | 0.00% |
| 平均完成任务数 | 6.35 / 8 | 2.79 / 8 |
| 超时回合比例 | 22.00% | 83.00% |
| 平均碰撞数 | 1.36 | 3.46 |
| 平均回合步数 | 278.24 | 454.82 |
| 评估回合数 | 100 | 100 |

在相同的 100 回合 holdout 集上，MAPPO-Guided 的安全服务完成率比 MAPPO-NoGuide 高 44.50 个百分点，平均每回合完成任务数增加 3.56 架，超时回合比例降低 61.00 个百分点。NoGuide 组的完整任务成功率为 0%，说明在当前规定时间窗内，策略很难使 8 架航空器同时完成任务。与此同时，NoGuide 的平均碰撞数更高、平均仿真步数更长，表明其低完成率并非仅由速度偏慢造成，而是与方向性决策不稳定、局部停滞和冲突积累有关。

## 4.3.4 机制解释

上述结果不应解释为 A* 路径直接替代了强化学习决策。A* 只提供参考路径和路径代价特征，策略仍然需要根据节点占用、邻近航空器、走廊状态和局部安全风险选择最终动作。Guided 组的优势体现在策略能够在执行安全约束和局部让行过程中维持全局目标方向，而不是机械地逐步跟随 A* 路径。

后续微观诊断应进一步报告两组模型的路径偏离指标、原始动作被执行器修改的比例和停滞触发重规划次数。若 Guided 组在完成率更高的同时具有更低的路径偏离、冲突保护介入和停滞重规划需求，则可以进一步说明 A* 先验改善的是策略的可执行性和目标一致性，而不仅是静态路径长度。

## 4.3.5 结果边界

本实验使用单一随机种子，因而不报告跨随机种子的统计显著性结论。由于 NoGuide 组表现显著低于 Guided 组，仍需通过统一的微观动作审计确认其主要失败模式，包括无效方向选择、连续等待、执行器保护介入和停滞重规划。相关结果应作为机制解释，而不替代固定评估集上的完整统计结果。
