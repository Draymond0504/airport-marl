# 4.3 A* 引导消融实验结果

本节最终结果统一采用 100 回合 holdout 集，不混用用于权重选择的 20 回合 evaluation 集。Guided 的 holdout 为安全服务完成率 79.375%、完整任务成功率 34.0%、timeout 22.0%；NoGuide 的对应结果为 34.875%、0.0%、83.0%。

## 4.3.1 实验目的与协议

为检验 A* 参考路径信息在规划引导多智能体协同中的作用，本文设置 MAPPO-Guided 与 MAPPO-NoGuide 两组实验。两组实验采用相同的机场港湾区拓扑、航班计划、连续飞机动力学、动作空间、奖励函数、训练回合数、随机种子和评估协议，唯一的模型输入差异是是否将 A* 参考路径特征加入航空器的局部观测。

在 MAPPO-Guided 中，A* 根据航空器当前位置和目标节点生成参考路径，并提取参考路径的下一节点、剩余路径代价和目标方向等信息。上述信息作为观测变量输入策略网络，用于提供目标导向的路径先验，但不直接规定航空器必须执行某一条边或某一个速度动作。策略仍需结合邻近航空器状态、节点与边资源占用、走廊状态以及局部安全约束输出动作。在 MAPPO-NoGuide 中关闭 A* 参考路径观测特征，同时保留相同的物理约束、动作掩码、奖励函数和执行环境。因此，该消融比较考察的是规划先验对策略观测和决策稳定性的影响，而不是比较两个不同的执行器。

最终性能采用独立的 100 回合 holdout 集进行确定性评估。训练期间用于选择权重的 20 回合 evaluation 集只用于模型筛选，不与最终 holdout 结果混用。本文将安全服务完成率定义为规定时间窗内完成且未发生安全失败的航空器比例；完整任务成功率定义为一个回合内 8 架航空器均在时间窗内完成任务的比例；未在时间窗内完成的任务统一记为 timeout，不表述为系统无法为其生成任何路径。

## 4.3.2 训练过程比较

图 4.1(a) 展示两组模型的训练回报滑动平均，图 4.1(b) 展示训练期间固定 evaluation 集上的确定性安全服务完成率。Guided 组在训练后期出现了多个较高性能评价点，并在第 9,500 个训练回合保存了本轮训练中的最佳选择模型；但评价曲线仍存在明显波动，因此不宜将其描述为严格意义上的单调收敛。NoGuide 组在第 2,000 个训练回合获得其最佳选择点，但后续评价长期维持在较低水平，且大多数评价回合仍以 timeout 结束。

从训练曲线看，A* 引导的主要作用不是保证每个训练回合的即时奖励持续增加，而是为策略提供从当前位置到目标区域的方向性参考，使其更容易形成可执行的目标导向行为。NoGuide 组仅依赖邻近航空器、目标状态和局部合法动作信息时，容易在多个局部可行分支之间反复选择，导致有效任务推进不足。由于多智能体场景中的冲突与释放顺序会改变局部可行动作集合，训练回报出现波动本身并不等同于模型没有学习；因此，本文将 holdout 完成率、timeout 和平均完成任务数作为主要判断依据，并将训练曲线用于说明学习过程和稳定性。

## 4.3.3 固定评估集结果

| 指标 | MAPPO-Guided | MAPPO-NoGuide |
|---|---:|---:|
| 安全服务完成率 | 79.38% | 34.88% |
| 完整任务成功率 | 34.00% | 0.00% |
| 平均完成任务数 | 6.35 / 8 | 2.79 / 8 |
| timeout 回合比例 | 22.00% | 83.00% |
| 平均碰撞记录数* | 1.36 | 3.46 |
| 平均仿真步数 | 278.24 | 454.82 |
| holdout 回合数 | 100 | 100 |

注：*“平均碰撞记录数”沿用当前训练环境的诊断字段，表示策略执行过程中记录到的安全冲突/碰撞事件，不能替代分层执行器测试中的最终安全违规数。论文最终基准和扰动实验应优先报告执行器输出的 `safety_violation_count`，该数值应为 0。

在相同的 100 回合 holdout 集上，MAPPO-Guided 的安全服务完成率比 MAPPO-NoGuide 高 44.50 个百分点，平均每回合完成任务数增加 3.56 架，timeout 回合比例降低 61.00 个百分点。Guided 的完整任务成功率为 34.00%，NoGuide 为 0%，说明在当前规定时间窗和 8 智能体并发条件下，NoGuide 难以使全部航空器同时完成任务。Guided 的平均仿真步数较少，也说明其较高的完成率并非单纯依靠延长运行时间获得。

需要注意的是，79.38% 的安全服务完成率并不意味着每个回合均能完成 8 架航空器。该指标是航空器层面的完成比例，而 34.00% 的完整任务成功率是回合层面的全完成比例，二者反映不同层次的性能。未在规定时间窗内完成的航空器应解释为运行服务超时，而不是系统无法为其生成任何路径。

## 4.3.4 微观动作审计与机制解释

为分析完成率差异的来源，本文在独立的 100 回合、确定性策略审计中记录节点决策、等待类型、沿边推进和冲突事件。该审计用于解释策略行为，不替代 holdout 性能结果，也不作为最终执行器安全指标。

| 微观诊断指标 | MAPPO-Guided | MAPPO-NoGuide |
|---|---:|---:|
| 节点决策次数 | 20,929 | 17,246 |
| 沿路由动作占比 | 37.73% | 70.08% |
| 强制等待占比 | 35.27% | 29.92% |
| 可避免等待占比 | 26.99% | 0.00% |
| 沿边无进展占比 | 11.07% | 9.76% |
| 有清晰参考方向但仍等待占比 | 17.56% | 不适用 |
| 审计阶段 clearance conflict 记录 | 74 | 182 |

上述数据不能简单解释为 Guided 的等待越少越好。NoGuide 的可避免等待为 0%，主要是因为该组在诊断过程中很少进入“存在清晰参考路径但策略主动等待”的可判定状态；其大量节点决策直接选择当前可行边，但这些局部移动并没有稳定转化为面向目标的任务推进。相反，Guided 组能够识别参考方向，并在局部冲突时进行等待、让行或改变局部选择，因此出现了一定比例的可避免等待和参考方向下的主动等待。这类等待是策略协调行为的一部分，不能直接等同于无效动作。

更有区分度的结果是，Guided 组在完成率显著更高的同时，审计阶段的 clearance conflict 记录由 182 降至 74，且 holdout 中的 timeout 大幅减少。这说明 A* 先验提供的作用主要体现在保持目标方向和减少错误分支，而不是简单提高沿边动作比例。NoGuide 的沿路由动作占比反而更高，但其平均完成任务数更低，说明移动得更多并不必然意味着有效完成得更多。

## 4.3.5 路径偏离指标

路径偏离指标可用于补充说明 Guided 是否保持全局路径一致性，但不应把偏离越小作为唯一优点。定义参考路径长度为 (L_{A^*})，策略最终执行轨迹对应的网络路径长度为 (L_{actual})，可采用归一化路径偏离指标：

\[
\mathrm{PDI}=\frac{L_{actual}-L_{A^*}}{\max(L_{A^*},\varepsilon)}.
\]

PDI 应在航空器确实进入运行并产生有效路径记录的样本上计算，不能将 timeout 航空器默认为 PDI=0，也不能删除无有效轨迹的样本而不报告样本数。当前动作审计没有输出 PDI，因此本节不填入估计值。待统一导出原始路径和执行器路径后，应报告两组的中位数、四分位距和有效样本数：

```text
Guided PDI median / IQR / N: [[guided_pdi_median]] / [[guided_pdi_iqr]] / [[guided_pdi_n]]
NoGuide PDI median / IQR / N: [[noguide_pdi_median]] / [[noguide_pdi_iqr]] / [[noguide_pdi_n]]
```

如果 Guided 的 PDI 较低且完成率较高，可以说明其在局部协调过程中保持了更强的全局目标一致性；如果 Guided 的 PDI 并不最低，但完成率和 timeout 更优，则应解释为策略利用 A* 作为软先验，在必要时允许绕行和让行，而不是机械跟随静态路径。

## 4.3.6 结果边界与论文表述

本消融实验使用单一训练随机种子和一个独立 holdout 种子，因而不报告跨随机种子的统计显著性结论。当前结果足以支持“在本实验拓扑、航班计划和时间窗下，A* 观测引导对 MAPPO 的可执行性和任务完成具有重要作用”，但不能据此宣称 Guided 在所有机场或所有交通密度下普遍优于 NoGuide。

论文中建议采用以下表述：

> A* reference information is not used as a hard route controller. It is encoded as a local planning prior and exposed to the decentralized policy together with local occupancy and safety information. The ablation results show that this prior substantially improves target-oriented coordination under the tested harbor-apron topology, reducing timeout and conflict accumulation. The result therefore supports the planning-guided MARL formulation, rather than an A* controller with a learned speed module.

对应中文可表述为：

> A* 信息并未作为强制路径控制器使用，而是与局部占用状态和安全信息共同编码为策略可利用的规划先验。消融结果表明，在本文测试的港湾区拓扑和时间窗条件下，该先验能够改善多智能体的目标导向协调，降低运行超时和冲突累积。因此，实验支持的是 planning-guided MARL 的观测融合机制，而不是将 A* 控制器与一个速度决策模块进行简单拼接。
