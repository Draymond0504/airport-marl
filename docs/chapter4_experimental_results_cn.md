# 第四章 实验设计与结果分析

## 4.1 实验设置

本章在 Layout F 所表示的港湾区滑行网络上检验所提出的 planning-guided MARL 框架。网络由外围滑行道、连接滑行道、港湾区内部走廊以及机位支路组成，连续运动、节点/边占用、走廊单向占用和翼尖净空等运行约束均由仿真环境统一处理。为避免将尚未放行的航班作为环境中的虚拟占用体，实验采用固定槽位的滚动执行机制：策略网络始终面对 8 个可复用智能体槽位，而尚未进入系统的航班仅保留在外部计划队列中。每个时刻可运行的航空器数量不超过 8 架。

航班计划取自筛选后的 08:00--24:00 时段，共包含 363 架次，其中目标航班 271 架次、过境航班 92 架次。原始计划的放行间隔远大于单架航空器的滑行时间，若直接按原始时刻执行，系统长期处于低并发状态，无法检验多智能体协调能力。因此，本文对所有方法和全部场景统一采用 0.10 的计划释放时间压缩系数。该处理不改变航班的起终点、相对先后关系和扰动规则，而是构造受控高负荷放行协议。在基准场景中，MAPPO 的平均活跃航空器数为 3.262，最大并发达到 8；FCFS+A* 的对应数值为 5.008 和 8。后者较高的平均活跃数主要来自局部等待累积，不能直接解释为更高的运行效率。

采用冻结的 `stage3_clearance_pilot_v1/best_eval.pt` 进行确定性推理，随机种子固定为 42，仿真时间步长为 1.127 s。为保证算法比较的公平性，两种方法均接受相同的滚动放行、入口间隔、连续净空保护、走廊占用和确定性 ATC 冲突过滤规则；区别仅在于冲突环境中的决策方式。MAPPO 依据局部观测和 A* 参考信息输出联合策略动作，FCFS+A* 按实际进入系统的先后顺序获得通行权，并采用 A* 生成可行路径。若航空器连续 180 步未发生实际位置或边进度变化，则判定为死锁并结束该航班。本章不设置重试，因此安全完航率、最终服务率在数值上相同，后续仅将安全完航率作为主指标。

表 4.1 汇总了实验协议。除特别说明外，所有指标均基于 363 架次完整计划统计。安全完航率定义为未经历碰撞且完成任务的航班比例；死锁和碰撞均按实际事件记录；平均总任务时间包括系统入口等待和在途滑行时间；吞吐率基于仿真时钟计算，因此仅用于不同方法之间的相对比较，不应直接解释为真实机场的小时容量。

## 4.2 基准场景性能比较

表 4.2 和图 4.1 给出了无外生扰动条件下的结果。MAPPO-Guided 完成 346 架航班，安全完航率为 95.32%，较 FCFS+A* 的 84.30% 提高 11.02 个百分点。两种方法均在相同的 8 槽位滚动框架中执行，因此该差异并非来自额外的并发资源。MAPPO 的平均总任务时间为 0.90 min，低于 FCFS+A* 的 1.68 min；其平均在途等待时间仅为 0.08 min，而 FCFS+A* 为 0.43 min。相应地，MAPPO 的仿真时钟吞吐率为 213.04 架次/h，高于 FCFS+A* 的 188.41 架次/h。

FCFS+A* 的路径规划能够为单架航空器提供可行的最短路参考，但其先到先服务规则主要处理局部通行顺序。当多个航班同时接近节点、机位支路或走廊入口时，该规则倾向于形成等待链，导致 29 次死锁事件和 28 次碰撞事件。MAPPO 的安全完航优势与更低的在途等待时间相对应：在 A* 参考路径限定总体运动方向的前提下，策略能够根据邻近占用、走廊方向和局部冲突状态调整推进时机，从而减少边上等待向系统级阻塞的累积。需要指出的是，平均滑行时间仅在完成航班中计算，不能脱离完成样本数单独比较。

| 指标 | MAPPO-Guided | FCFS+A* |
|---|---:|---:|
| 安全完航率 (%) | 95.32 | 84.30 |
| 完成航班数 | 346 | 306 |
| 碰撞事件数 | 12 | 28 |
| 死锁事件数 | 5 | 29 |
| 平均在途等待时间 (min) | 0.08 | 0.43 |
| 平均总任务时间 (min) | 0.90 | 1.68 |
| 仿真时钟吞吐率 (架次/h) | 213.04 | 188.41 |
| 平均活跃航空器数 | 3.262 | 5.008 |

## 4.3 A* 引导作用的消融设计

本研究将 A* 作为局部策略的结构化先验，而非替代多智能体决策模块。消融实验应在保持网络、航班计划、随机种子、奖励函数、训练预算和安全执行机制一致的条件下，仅关闭 `use_astar_guide`，比较 MAPPO-Guided 与 MAPPO-NoGuide 的训练确定性评估曲线、安全完航率、死锁率和碰撞率。该比较检验参考路径代价、参考下一节点和路径进度特征是否有助于降低多智能体探索中的无效等待与局部回退。

当前冻结模型的开发过程经历过运行时恢复逻辑修复，现有训练曲线不能与未引导模型构成同实现条件下的严格对照。因此，本章不将已有奖励曲线作为 A* 消融的实证结果，也不报告未经匹配训练的 NoGuide 数值。待以最终运行语义完成 MAPPO-NoGuide 训练后，可在本节补充表 4.3 及“Guided/NoGuide”确定性评估收敛图。该处理避免将运行机制修复造成的变化误判为 A* 引导的贡献。

## 4.4 动态扰动下的鲁棒性

### 4.4.1 三类扰动的总体表现

表 4.4 和图 4.2 汇总了延误释放、滑行道封闭和优先级变化三类扰动下的结果。MAPPO-Guided 在三个场景中的安全完航率分别为 95.04%、94.21% 和 94.77%，相对于基准场景的变化不超过 1.11 个百分点。FCFS+A* 在相同场景中的安全完航率分别为 88.15%、83.47% 和 84.30%。尤其在封闭场景中，MAPPO 的安全完航率较 FCFS+A* 高 10.74 个百分点，且死锁频率显著更低。

从系统时间指标看，MAPPO 在三个扰动下的平均总任务时间维持在 0.75--0.90 min，吞吐率为 210.57--212.42 架次/h。FCFS+A* 的总任务时间在延误释放场景中上升至 2.61 min，在封闭场景中为 1.78 min。这说明规划结果本身并不足以避免拥堵扩散；在动态状态下，还需要根据局部占用和冲突关系协调实际进入、等待与推进时机。

### 4.4.2 延误释放与等待响应

延误场景将原计划中受影响的到达航班重新安排在统一的释放窗口中，使系统在局部时段经历集中放行压力。图 4.4 展示了两种方法的等待时间分布。MAPPO 的平均总任务时间为 0.75 min，低于 FCFS+A* 的 2.61 min；同时，MAPPO 的死锁频率由 FCFS+A* 的 7.44 次/100 架次降至 0.55 次/100 架次。累计完航曲线表明，MAPPO 在扰动窗口后保持连续的服务增长，而 FCFS+A* 更容易在局部等待累积后出现较长的恢复过程。

需要避免将该结果解释为所有延误模式下的普遍优势。本实验中的延误表现为特定到达批次的重新释放，其作用取决于原始放行结构、受影响航班的起终点以及港湾区当时的占用状态。因此，本节的结论限定为：在给定的集中释放扰动下，MAPPO 能够以较低的在途等待和死锁代价维持服务过程。

**图 4.4** 延误释放场景下两种方法的总等待时间箱线图；图中以秒为单位展示低等待区域，菱形表示均值。

### 4.4.3 封闭感知的重规划与局部流量调整

封闭场景在滚动运行过程中关闭链路 (102, 103)，持续 800 个仿真步。触发时，执行器基于当前可用拓扑重新生成活动航班的参考路径；MAPPO 的局部观测同时反映邻居占用、可行行动和参考路径状态。图 4.5 以关闭前后两个等长窗口内实际完成的边通过次数绘制网络边使用图，颜色和线宽均采用统一尺度，深红虚线表示关闭链路。

结果表明，封闭发生后 MAPPO 的完成过程仍保持平稳，其安全完航率为 94.21%，平均总任务时间为 0.90 min。FCFS+A* 的安全完航率下降至 83.47%，死锁频率达到 8.81 次/100 架次。该差异并不意味着 MAPPO 在每个局部节点都选择更短路径，而是表明参考路径更新与局部协调共同避免了部分航空器在受阻区域前形成持久边上队列。由于图 4.5 反映的是固定事件窗口内的实际通过次数，而非全局时段的标准化流量估计，它用于说明路径和流量的局部调整机制，不作为严格的时间窗口需求比较。

### 4.4.4 优先级变化下的局部协调

优先级场景对预设航班依次施加持续 300 步的优先级提升。为避免只报告高优先级航班的获益，本节同时比较高优先级航班、普通航班以及系统整体的服务表现。MAPPO 中完成的高优先级航班平均滑行时间为 0.48 min，普通完成航班为 0.85 min，对应 43.4% 的相对缩短；FCFS+A* 中两类航班的对应数值为 0.60 min 和 1.07 min。两种方法均能响应显式的优先级规则，但 MAPPO 在保持优先级航班快速推进的同时，仍取得 94.77% 的安全完航率和 0.90 min 的平均总任务时间；FCFS+A* 的对应数值为 84.30% 和 1.65 min。

## 4.5 讨论与局限性

上述结果支持 planning-guided MARL 在所构建的港湾区复杂运行环境中的协调能力：A* 提供面向目标的拓扑参考，MAPPO 在此基础上利用局部冲突、占用和优先级信息决定推进或等待时机。相较于基于先到先服务排序的 FCFS+A*，该框架在基准和三类扰动场景中均表现出更高的安全完航率、更低的死锁频率以及更短的系统任务时间。

结论仍受到若干条件限制。第一，全部结果基于单一随机种子和同一航班计划，不应报告跨种子显著性结论。第二，0.10 的时间压缩系数构造了用于测试协调能力的受控高负荷协议，其吞吐率不能直接外推为真实机场容量。第三，连续净空保护、走廊占用和入口间隔属于两种方法共享的安全执行机制，本文评估的是该运行约束下 planning-guided MARL 与 FCFS+A* 的整体表现，而非脱离运行规则的纯策略能力。第四，严格的 MAPPO-Guided 与 MAPPO-NoGuide 消融尚需在最终运行语义下完成匹配训练，A* 引导的定量贡献应在该实验完成后单独报告。
